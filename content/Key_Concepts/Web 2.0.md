# Web 2.0

**Web 2.0 là tập hợp các dịch vụ web tạo điều kiện cho người dùng tương tác với site để tạo nội dung (user-generated content) và khuyến khích hành vi như tham gia cộng đồng/mạng xã hội, mashup, đánh giá nội dung, dùng widget và gắn thẻ.**

## Giải thích
- Bước ngoặt từ web ĐỌC (1.0 — publisher đăng, người dùng xem) sang web ĐỌC-VIẾT: blog, wiki, mạng xã hội, review — người dùng trở thành người tạo nội dung.
- Hệ quả kinh doanh: [[Social Media Marketing]], [[Community]], sức mạnh review/[[Social Proof]], nền tảng [[C2C]].
- Tiếp nối: Web 3.0 (semantic web thông minh) và [[Web3]] (phi tập trung với [[Blockchain]]) — CH01 vẽ tiến trình Web 1.0 → 2.0 → 3.0.
- Công nghệ nền: AJAX, API mở, RSS, widget.
